# Hero Background Image - Setup Instructions

## Required Image
- **Filename**: `hero-background-placeholder.jpg`
- **Location**: `public/images/hero-background-placeholder.jpg`
- **Recommended Dimensions**: 1920x1080px (or higher for retina displays)
- **Format**: JPG or PNG
- **Subject**: Workshop/factory floor, signage showroom, or professional craftsmanship scene
- **Style**: Professional photography with warm industrial lighting

## Current Status
⚠️ **Placeholder image needed** - The component is ready but requires a background image.

## To Add Your Image:
1. Obtain the background image from the client
2. Save it to: `public/images/hero-background-placeholder.jpg`
3. The image will automatically appear on the hero section

## Temporary Solution:
Until the client provides the image, you can:
- Use any high-quality workshop/industrial image
- Download a free stock photo from Unsplash/Pexels
- Take a photo of the R.M BATT workshop

## Alternative Paths:
If you want to use a different image path, update line 13 in:
`src/components/Hero.tsx`
